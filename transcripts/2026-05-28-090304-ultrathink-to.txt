  Networking strategy

  Each compose stack creates an isolated bridge network by default — that's the
  right starting point. When stacks need to talk to each other (e.g., n8n calls
  LiteLLM, Stirling-PDF invoked from an n8n workflow), two clean options:

  1. Host gateway (simplest): use http://host.docker.internal:<port> — works
  because OrbStack maps it to the Mac host, and your ports are exposed there.
  2. Shared external network: docker network create dev-shared once globally,
  then add to each stack:
  networks:
    dev-shared:
      external: true
  2. Containers reach each other by service name across stacks. Better isolation
   than host gateway, no port plumbing.

  For dev on one Mac, start with #1; switch to #2 if you ever expose these
  publicly via a reverse proxy.

  logs stream live per service.

      110 +## AI configuration (LiteLLM)                                 
      111 +                                                              
      112 +### How it works                                              
      113 +                                                              
      114 +Postiz sends OpenAI-format API calls to `http://litellm:4000/v
          +1` (set via `OPENAI_BASE_URL` in `.env`). LiteLLM:            
      115 +                                                              
      116 +1. Looks up the model name (`gpt-4o-mini`, `claude-sonnet`, `l
          +ocal-fast`, …) in `litellm/config.yaml`.                      
      117 +2. Calls the upstream provider using its key from the containe
          +r env.                                                        
      118 +3. If the provider fails (no key / 401 / rate limit), tries th
          +e next entry in its `fallbacks` block.                        
      119 +4. Eventually falls back to local Ollama (`local-fast` = `llam
          +a3.2:3b`).                                                    
      120 +                                                              
      121 +### Editing the model list                                    
      122 +                                                              
      123 +The config file lives **outside this repo** at `/Volumes/<ssd>
          +/postiz/litellm/config.yaml` (mounted into the LiteLLM contain
          +er). Example entries:                                         
      124 +                                                              
      125 +```yaml                                                       
      126 +model_list:                                                   
      127 +  - model_name: gpt-4o-mini                  # what Postiz ask
          +s for                                                         
      128 +    litellm_params:                                           
      129 +      model: openai/gpt-4o-mini              # what LiteLLM ac
          +tually calls                                                  
      130 +      api_key: os.environ/OPENAI_API_KEY                      
      131 +                                                              
      132 +  - model_name: claude-sonnet                                 
      133 +    litellm_params:                                           
      134 +      model: anthropic/claude-sonnet-4-6                      
      135 +      api_key: os.environ/ANTHROPIC_API_KEY                   
      136 +                                                              
      137 +  - model_name: local-fast                                    
      138 +    litellm_params:

      141 +

      312 +                                                              
      313 +### Postiz container restart-loops                            
      314 +                                                              
      315 +```bash                                                       
      316 +docker compose -f docker-compose.yaml -f docker-compose.litell
          +m.yaml logs --tail=200 postiz                                 
      317 +```                                                           
      318 +                                                              
      319 +Common causes (most → least common):                          
      320 +1. `JWT_SECRET` empty — fill in `.env`, then `docker compose u
          +p -d --force-recreate postiz`.                                
      321 +2. Postgres not ready — wait 30 s, check `docker compose logs 
          +postiz-postgres`.                                             
      322 +3. Temporal unreachable — Elasticsearch needs ≥ 512 MB headroo
          +m in OrbStack; bump RAM in OrbStack Settings.                 
      323 +                                                              
      324 +### Frontend returns connection-refused                       
      325 +                                                              
      326 +```bash                                                       
      327 +docker compose ps postiz       # is it Up?                    
      328 +docker compose port postiz 5000 # what host port is mapped?   
      329 +lsof -nP -iTCP:4007 -sTCP:LISTEN                              
      330 +```                                                           
      331 +                                                              
      332 +### macOS Keychain popup during `docker compose pull`         
      333 +                                                              
      334 +`credsStore: osxkeychain` triggers a prompt. Either click **Al
          +ways Allow** in the popup, or remove the key:                 
      335 +                                                              
      336 +```bash                                                       
      337 +python3 -c "import json; p='/Users/$USER/.docker/config.json';
          + d=json.load(open(p)); d.pop('credsStore',None); json.dump(d,o
          +pen(p,'w'),indent=2)"                                         
      338 +```                                                           
      339 +                                                              
      340 +### LiteLLM returns 401 / unknown model                       
      341 +                                                              
      342 +```bash                                                       
      343 +LMK=$(grep ^LITELLM_MASTER_KEY .env | cut -d= -f2)            
      344 +curl -fsS -H "Authorization: Bearer $LMK" http://localhost:400
          +0/v1/models | jq -r .data[].id                                
      345 +```                                                           
      346 +                                                              
      347 +Model not listed? Edit `/Volumes/<ssd>/postiz/litellm/config.y
          +aml`, then `docker compose restart litellm`.                  
      348 +                                                              
      349 +### Containers gone after Mac sleep / SSD unmount             
      350 +                                                              
      351 +OrbStack's VM dies when `/Volumes/<ssd>` unmounts. To prevent:
      352 +                                                              
      353 +1. **System Settings → Energy → "Put hard disks to sleep"** → 
          +OFF.                                                          
      354 +2. Don't manually eject the SSD.                              
      355 +                                                              
      356 +To recover after the fact: remount the SSD, `orb start`, then 
          +`docker compose up -d`.                                       
      357 +                                                              
      358 +### OrbStack stuck "Starting"                                 
      359 +                                                              
      360 +```bash                                                       
      361 +orb stop && sleep 3 && orb start && sleep 30 && orb status    
      362 +```                                                           
      363 +                                                              
      364 +`orb start` is more reliable than `open -a OrbStack` for kicki
          +ng the VM.                                                    
      365 +                                                              
      366 +### "host.docker.internal" doesn't resolve                    
      367 +                                                              
      368 +OrbStack provides it; if it ever fails, substitute your Mac's 
          +LAN IP (`ipconfig getifaddr en0`) in `litellm/config.yaml` for
